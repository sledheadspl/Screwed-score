Pokebank chat mod bot
=====================

Removes bad messages. Mutes whoever keeps sending them. Says nothing.


START HERE
----------
Double-click:   Pokebank Mod Bot.cmd

The first time, it spends about 20 seconds setting itself up, and offers
to put an icon on your Desktop.

Every time after that: double-click the Desktop icon, paste your stream
link, press Enter. That is the whole job.


WHAT THE FIRST RUN ASKS OF YOU
------------------------------
Chrome has no way to be told "install this" from a script, so this one
step is yours. The launcher opens both windows you need, side by side:

  1. In the Chrome window, turn ON "Developer mode" (top right)
  2. Drag the folder from the Explorer window onto the Chrome window

That installs it. You never do it again.


EVERY STREAM
------------
Double-click the icon and paste any of these - it works them all out:

    https://www.youtube.com/watch?v=dmVCwUZT48s
    https://youtu.be/dmVCwUZT48s
    https://www.youtube.com/live/dmVCwUZT48s
    dmVCwUZT48s

A channel link (youtube.com/@Pokebank) will NOT work - it has no video in
it. Open the stream itself and copy the link from the address bar.

The chat opens in its own small window. Leave it somewhere you can see
it: Chrome slows hidden windows down, and clicking the menu depends on
timers.


IS IT WORKING?
--------------
Click the extension icon. The top line tells you, in words:

  "Watching this chat - 12 messages seen."
        Working. Nothing else to do.

  "This account cannot moderate this chat."
        You are signed in as a viewer here. YouTube shows that account no
        moderation menu, so nothing can be removed. Sign in as the channel
        owner, or have this account made a moderator.

  "Chat window is hidden."
        Bring it back on screen.

  "No live chat open." / "the extension is not running in it."
        Reload the chat window.

If it says something else, or nothing, send me that line.


DRY RUN FIRST
-------------
It starts in Dry run: it logs what it WOULD remove and touches nothing.
Watch one stream that way and read the list.

Then switch to "Ask me", post a test message from a second account that
trips a word, and tap Delete when it appears. Dry run never opens a
message menu, so that is the only way to know removal works on YOUR
account.

Then "Auto". A deletion cannot be undone - that is the reason for the
order.


WHAT IT DOES BY DEFAULT
-----------------------
Removes  hate, harassment, doxxing, spam and scam links, and swearing.
Mutes    anyone who trips the rules twice - a timeout, which expires.
Never    bans. Raise the ceiling in Settings if you want that.
Never    posts in your chat. Nothing is sent to Claude at all.
Never    touches your own messages, your mods', or anything a mod already
         handled.

Catches f@ck, shiiit, fu(Cyrillic c)k, f.u.c.k and fucking. Misses "fu ck"
on purpose - closing that gap starts flagging "he's hit".

Settings has the word list, an allow list for false positives, and the
ceiling on how far it will go. Nothing else needs touching.
